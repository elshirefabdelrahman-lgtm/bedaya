# موقع مركز بداية للطب النفسي وعلاج الإدمان

موقع عربي RTL ثابت متعدد الصفحات للتعريف بخدمات مركز بداية والفريق والفروع وطرق التواصل. المشروع مبني ليعمل مباشرة على استضافة Static مثل Vercel، دون قاعدة بيانات أو Backend.

> المحتوى الطبي ومعلومات الفريق والفروع مأخوذة من بيانات المشروع. تظل بعض التفاصيل بحاجة إلى اعتماد إدارة المركز قبل الإطلاق العام.

## التقنيات

- HTML5 وCSS3.
- Vanilla JavaScript.
- لا توجد عملية Build أو حزم مطلوبة.
- لا توجد API خارجية أو مفاتيح سرية.
- لا توجد Analytics أو Tracking.

## التشغيل محليًا على Windows

يتطلب Node.js فقط. من PowerShell داخل مجلد المشروع:

```powershell
node serve.js
```

ثم افتح:

```text
http://127.0.0.1:8080/
```

لإيقاف الخادم اضغط `Ctrl+C`.

## البنية المشتركة

```text
assets/
  css/styles.css
  js/site-data.js
  js/main.js
  js/pages.js
  images/
    brand/
    hero/
    programs/
    team/
    branches/
branches/
```

- `assets/css/styles.css`: نظام التصميم، الاستجابة والمكونات المشتركة.
- `assets/js/site-data.js`: المصدر المركزي لبيانات التواصل والفروع والبرامج والفريق.
- `assets/js/main.js`: Header وFooter والقائمة والأسئلة الشائعة والحركة.
- `assets/js/pages.js`: بطاقات الفريق ومعارض الفروع.
- `ASSET-MAPPING.md`: خريطة الأصول الأصلية والنسخ المستخدمة.

## التحقق المحلي

شغّل الفحص الآلي:

```powershell
node qa.js
```

يفحص الصفحات المطلوبة، Title وH1 وDescription، الروابط والملفات المحلية، صياغة JavaScript، أرقام التواصل، وعدم وجود نطاق placeholder في ملفات الإنتاج.

بعدها شغّل `node serve.js` وافحص يدويًا:

- القائمة على الهاتف وسطح المكتب.
- الهاتف وواتساب والخرائط.
- الصور المؤجلة بعد التمرير.
- Console المتصفح.

## حالة SEO والدومين

الدومين الرسمي غير مؤكد. لذلك:

- لا توجد Canonical tags مؤقتة بدل اختراع نطاق.
- `sitemap.xml` صالح لكنه فارغ مؤقتًا ولا يحتوي نطاقات وهمية.
- `robots.txt` لا يعلن رابط Sitemap غير مؤكد.
- صفحة أسيوط تحمل `noindex,follow` ولا يجب إضافتها إلى Sitemap قبل اكتمالها.

بعد اعتماد الدومين:

1. أضف Canonical مطلقًا وفريدًا لكل صفحة قابلة للفهرسة.
2. أضف `og:url` وروابط Open Graph المطلقة عند الحاجة.
3. املأ `sitemap.xml` بروابط HTTPS المطلقة للصفحات القابلة للفهرسة فقط.
4. أضف `Sitemap: https://OFFICIAL-DOMAIN/sitemap.xml` إلى `robots.txt`.
5. لا تضف `branches/assiut.html` حتى اكتمالها وإزالة `noindex` بقرار واعٍ.

## بيانات تحتاج إلى اعتماد

- عنوان ورابط خريطة فرع أسيوط.
- هل مجلد صور `مركز بداية 3` يخص فرع أسيوط فعلًا؟
- مطابقة صورة د. مصطفى أحمد للاسم الكامل.
- المسمى النهائي لأ. مريم مجدي صموئيل.
- المؤهلات والمسميات المهنية وموافقات نشر الصور.
- مصدر واعتماد صورة الغلاف وصور البرامج.
- الخدمات المتاحة في كل فرع وساعات العمل.
- مراجعة سياسة الخصوصية قانونيًا.

## Vercel لاحقًا

بعد اعتماد المحتوى والدومين يمكن ربط مستودع GitHub بمشروع Vercel كـStatic Site. لا يلزم Build Command؛ يكون Root Directory هو جذر المستودع. راجع الدومين وHTTPS والروابط و404 وملفات SEO بعد أول نشر. هذا المستودع لا ينفذ النشر تلقائيًا من داخل التعليمات الحالية.
